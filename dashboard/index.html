How the value is worked out

Every implied value on this board follows one formula, from the snapshot's own figures:

implied value = TVL × multiple × growth multiplier × maturity multiplier

  • Multiple. Protocols whose token already trades have a market-cap-to-TVL ratio. A pre-token protocol inherits the median ratio of its category — but only when that category has at least 5 traded protocols. With fewer, it inherits the global median of 0.1857 across all 133 traded, non-CEX protocols. Ratios are winsorised to [0.02, 5.0] before any median is taken, so one outlier cannot set the price. A 0.25 fallback exists in the code but is unreachable while any traded protocol exists.
  • Growth multiplier. 1 + (7-day TVL change, clamped to [−60%, +120%]) × 0.5. A protocol with no 7-day figure gets 1.00.
  • Maturity multiplier. 0.6 + min(age in days, 1095) / 1095 × 0.4. A protocol with no listed date is assumed to be 365 days old.

Read this honestly. An implied value is what a token would be worth if one were issued at the market's usual ratio for its category. It is not a prediction that a token will be issued, or when. The top of the board is still bridge- and wrapped-heavy, because bridges hold the most TVL; the rules say nothing about whether a bridge will ever launch a token. And more than 40% of rows use the global median, because their category has too few traded comps to trust — Risk Curators, the watchlist's largest category at 12 of 40, has only one traded comp, so every Risk Curator row is priced at the global 0.1857. Each protocol's detail view says plainly whether its multiple is its category median or the global median.
